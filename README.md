# 📊 Attendance Management App is an Android application that helps manage attendance records for students and employees using Firebase. It supports complete CRUD operations, allowing users to create, view, update, and delete attendance records through a simple and organized interface.

# ✨ Features
* 👨‍🎓 Student Attendance – Record and manage attendance for students.
* 👨‍💼 Employee Attendance – Maintain attendance records for employees.
* ➕ Add Attendance – Create new attendance records.
* 👀 View Attendance – View stored attendance information.
* ✏️ Update Attendance – Modify existing attendance records.
* 🗑️ Delete Attendance – Remove attendance records when required.
* 🔄 CRUD Operations – Complete Create, Read, Update, and Delete functionality.
* 🔥 Firebase Integration – Store and manage attendance data using Firebase.
* ⚡ Real-Time Data – Keep attendance information synchronized with Firebase.
* 📱 Simple UI – Easy-to-use interface for managing attendance records.
